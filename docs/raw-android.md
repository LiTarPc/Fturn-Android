# RAW VPN

RAW — отдельный режим подключения к серверу FturnRaw. Он передаёт трафик через TURN без WireGuard-конфига и без VLESS UUID. Профиль обычного WG/VLESS-сервера не превращается в RAW-профиль при переключении режима в приложении.

В Fturn 4.3.9 включено ядро `1.1.0-captcha.1`: проверенная основа RAW 1.1.0 с исправлением загрузки ресурсов ручной капчи. Версия клиента показывается в «О приложении». Серверные возможности зависят от установленного серверного ядра.

## Подключение

1. Получите от владельца сервера ссылку `fturnraw://`.
2. Импортируйте её через добавление сервера или QR-код.
3. Выберите профиль, подключитесь и разрешите Android создать VPN.
4. Дождитесь готового RAW-потока и проверьте сайт. Успешная авторизация VK сама по себе ещё не подтверждает связь с RAW-сервером.

Поддерживаются версии формата 1–4. В зависимости от версии ссылка передаёт адрес сервера, VK-звонок, ключ, RTP-профиль, MTU, число потоков, потоки на одни реквизиты, транспорт TURN и режим исходящего трафика.

## Параметры, которые должны соответствовать серверу

| Параметр | Что проверить |
|---|---|
| Адрес сервера | Это адрес RAW-сервера из профиля, а не локальный IP телефона |
| Общий ключ и RTP-профиль | Должны совпадать с настройками сервера |
| RAW MTU | Должен соответствовать серверу; допустимый диапазон клиента 576–1500 |
| Внутренний IPv4 | По умолчанию `10.77.0.2/24`; при нескольких устройствах может потребоваться отдельный адрес для каждого |
| Число потоков | 1–64 суммарно с учётом числа ссылок на звонки |
| Потоки на одни реквизиты | 1–64; значение из профиля не следует менять без причины |
| Исходящий режим | `packet` или `tcp-flow`, согласно профилю |

MTU RAW и MTU локального IP-туннеля роутера — разные настройки. Смена одного не должна автоматически менять другое.

## Что поддерживается

Приложение использует общий VPN-движок sing-box для Android TUN, выбора приложений, DNS, обхода сайтов и раздачи. RAW-ядро подключено к нему через приватный адаптер. Root не нужен.

Трафик, вошедший в VPN, обрабатывается в IPv4. Поддерживаются TCP и UDP; проверять работу только командой ping некорректно, поскольку ICMP через RAW-мост не поддерживается. Обычные DNS-запросы направляются через выбранный VPN. Приложения, исключённые из VPN, используют собственное соединение.

Метки `full` и `tunnel` в исходной RAW-ссылке не заменяют настройки разделения трафика Android. Выбирайте нужные приложения и обход сайтов в Fturn.

## Если не подключается

- При ошибках VK проверьте ссылку на звонок и [состояние авторизации](captcha.md).
- При `encrypted handshake timed out` проверьте доступность сервера, общий ключ, RTP-профиль, MTU и внутренний адрес клиента.
- При ограничении числа устройств сначала отключите старую сессию и уточните лимит у владельца сервера.
- При сбоях после смены Wi-Fi/мобильной сети переподключите профиль и сохраните диагностический журнал с моментом обрыва.

Сетевые тайм-ауты могут зависеть от оператора, вложенного VPN и удалённого сервера. Обновление клиента не исправляет произвольную серверную конфигурацию и не добавляет старому серверу поддержку нескольких устройств.
