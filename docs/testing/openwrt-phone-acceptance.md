# Проверка OpenWrt-настройки на Android с эмулятором роутера

Проверка выполнена 16 ноября 2026 на физическом Android 13 с отдельным пакетом com.litar.freeturn.routerip. Основной Fturn и сохранённые VPN-профили не использовались для тестового трафика.

## SSH и экран приложения

ПК запускал loopback-only Paramiko SSH fixture. По ADB reverse телефон подключался к нему как к SSH-роутеру. Выполнялся установщик из APK; пакеты, netifd, firewall и службы OpenWrt были изолированными макетами внутри каталога .native. Windows network configuration не изменялась установщиком.

Подтверждены через настоящий экран приложения и аудит SSH:

- неверный пароль отклоняется до выполнения команд;
- установка из APK завершается, создаёт привязку и включает службу;
- сброс в Fturn отключает режим и удаляет код;
- сброс по SSH отключает службу, удаляет код и восстанавливает исходную DNS-конфигурацию;
- изменившийся SSH-ключ блокирует дальнейшую настройку.

Файлы воспроизведения: scripts/tests/openwrt_ssh_fixture.py, scripts/tests/phone_router_ui.py. Для fixture требуется Python paramiko; сервер слушает только 127.0.0.1 и принимает только точный установочный payload из тестового APK или фиксированную команду сброса. Он не предназначен для запуска на внешнем интерфейсе.

## Настоящий FOU по USB

В Android временно включён обычный USB-модем. На телефоне запущен RouterFouInstrumentation: настоящая libbox с FOU-входом и локальными TCP/UDP echo-серверами, без создания Android VPN TUN. Пользовательский VPN-сервер не задействован.

ПК запускал scripts/tests/fou_echo_probe.go: пользовательский сетевой стек имитировал два LAN-адреса и передавал IPv4-пакеты внутри UDP по реальной USB-сети к телефону.

Результаты:

| Проверка | Результат |
|---|---|
| Неверный код привязки | HTTP 401 |
| Публичная LAN с верным кодом | HTTP 400 |
| Частная LAN, отличная от фиксированного fallback | HTTP 200, разрешённая подсеть обновлена |
| TCP для первого LAN-хоста | 128 КиБ echo, данные совпали |
| UDP для первого LAN-хоста | 5 × 1200 байт echo, данные совпали |
| TCP для второго LAN-хоста | 128 КиБ echo, данные совпали |
| UDP для второго LAN-хоста | 5 × 1200 байт echo, данные совпали |
| Завершение FOU-приёмника Android | PASS, без VPN TUN |

Тестовый runner собирается с параметром -PvpnFixtureRunner=com.freeturn.app.testing.RouterFouInstrumentation. Он использует отдельные порты, фиксированный публичный тестовый код и локальный echo-target; обычная работа Fturn этого runner не запускает. Продолжительность ограничена, при завершении listener закрывается.

## Границы проверки

Это подтверждение экрана/SSH-установщика и настоящего FOU-пути на Android, а не установки модулей в настоящее ядро OpenWrt. Пакетный менеджер, netifd и firewall дополнительно проверяются 20 сценариями scripts/tests/test_router_openwrt.py на макетах fw3/fw4. Реальный парк роутеров, производительность удалённого RAW-сервера и многочасовая стабильность требуют отдельных испытаний.

ADB использовался для автоматизации теста, установки отдельного APK и instrumentation. Пользовательской SSH-настройке и последующей работе USB-модема ADB не требуется.
