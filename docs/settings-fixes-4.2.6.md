# Настройки и исправления аудита — 4.2.6

## Интерфейс

- Четыре корневых раздела: Серверы, VPN, Приложение, О приложении.
- Создание и восстановление резервной копии находятся вместе; прежний вход из добавления сервера сохранён.
- Обновления перенесены к версии приложения. Переключатели предложений обновлений/Telegram имеют положительные подписи, хранимые значения suppress не менялись.
- VPN объединяет приложения, сайты/подсети напрямую и раздачу через SOCKS5. Правила привязаны к указанному профилю; раздача отмечена как общая настройка. Неактивный профиль можно редактировать без его активации.
- Выбор приложений: все, только выбранные, все кроме выбранных. Убран дополнительный переключатель включения выбора.
- Параметры подключения объединены в один экран с вкладками TURN и Прокси/VPN. Технические механизмы и ограничение входа режимом отладки сохранены.
- Диагностика находится внутри Приложения. Перезапуск сервера при переключении находится в диагностике и виден только в режиме отладки; основной список серверов содержит профили.
- Два переключателя журнала заменены одним выбором: выключен, обычный, подробный. При выключении сохраняется прежний флаг подробности ядра; при выборе обычного/подробного оба поля обновляются одной транзакцией.
- Переименованы приватный режим и тема. Ключи настроек и сохранённые значения совместимы с 4.2.5.

## Надёжность

- При выходе из настройки TURN последняя правка передаётся в ViewModel, даже если 600 мс задержки ещё не прошли. Запись привязана к конкретному id профиля.
- Импорт резервной копии строго проверяет версию, наличие массива профилей, ошибки отдельных записей, повторяющиеся id и существование активного профиля до остановки подключения и замены данных.
- При локальном чтении повреждённая запись больше не скрывает все здоровые профили. Перед следующей записью оригинальный JSON сохраняется в отдельном ключе servers_json_recovery внутри DataStore. Это техническая страховка, а не полноценный интерфейс восстановления повреждённых профилей.
- Размер зашифрованного файла ограничен 64 МиБ, открытого содержимого — 47 МиБ, WG-конфигурации — 256 КиБ. Ограничение проверяется во время чтения. Экспорт также проверяет предел, чтобы не создавать неимпортируемые копии.
- До PBKDF2 проверяются версия конверта, KDF, число итераций (1–1 000 000), размеры salt/IV/тега. Экспорт по-прежнему использует 210 000 итераций и AES-256-GCM.
- Удалён повторный запрос разрешения уведомлений из Activity: остаётся существующая последовательность на главном экране.
- Таймер длительности подключения работает только при STARTED lifecycle.
- Изменение темы и других общих настроек больше не запускает повторный разбор JSON профилей в каждом действующем коллекторе.
- Android Lint добавлен в CI вместе с unit-тестами.

Для release-сборки потребовалось скачать отсутствующую в offline-кэше зависимость compose-group-mapping:2.4.0; после этого сборка успешна. Команда проверки:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleRelease :app:lintDebug -PpreviewBuild=true -PrawBuild=false -PcoreFetch=none -x :app:buildRawCore --offline --console=plain
```

Нативные ядра в локальной проверке переиспользуются без пересборки. Установка поверх основного Fturn требует исходного release-сертификата; подпись локального debug-keystore не подходит. Основной пакет не удалялся и данные не очищались.

Предложения аудита, требующие отдельного измерения или миграции, в этот набор не включены: счётчики полезного трафика вместо UID/2, изменение wake lock, частота уведомлений, пакетирование логов, шифрование полей через Android Keystore, перенос файлов правил из DataStore, уменьшение нативных библиотек и Baseline Profiles. Численного улучшения батареи, пропускной способности или времени запуска здесь не заявляется.

Шесть изменений жизненного цикла VPN, уже находившихся в рабочем дереве до этой задачи, сохраняются отдельно и не включаются в коммит настроек.
