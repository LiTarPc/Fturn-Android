# Fturn v4.0.0

Fturn теперь использует sing-box для WireGuard и VLESS. Импорт существующих ссылок и WG-конфигов сохранён.

- Добавлен импорт VLESS TCP без TLS из поля `sb` в ссылках FreeTurn.
- WireGuard перенесён в общий VPN-сервис sing-box 1.12.0.
- Ядро FreeTurn обновлено до v4.1.3.
- Список RU IPv4 от IPdeny встроен в APK и включён по умолчанию. Доступны обновление списка и импорт `.srs`, `.zone` и `.txt`.
- В раздельном туннелировании по умолчанию отмечены известные российские приложения и установленные приложения с сегментом `ru` в имени пакета: `ru.*`, `*.ru.*`, `*.ru`. Отмеченные приложения в режиме исключений работают напрямую. Ручной выбор сохраняется.
- VPN использует IPv4; IPv6-подключения отклоняются. Обычные DNS-запросы перенаправляются через выбранный VPN.
- Исправлены два одновременно отображавшихся уведомления и задержка обработки больших списков правил.
- Название приложения — Fturn.

Android 7.0+ (API 24), arm64-v8a. Пакет `com.litar.freeturn` сохранён для обновления существующей установки. Release APK подписан ключом проекта.

VLESS поддерживает TCP с `encryption=none` и `security=none`; удалённый сервер FreeTurn должен быть настроен на соответствующий VLESS-вход. TLS/REALITY, WebSocket и gRPC пока не поддерживаются. Приложения, исключённые из VPN, используют собственные подключения и DNS.
