# Fturn 4.2.1

- Обычное ядро для WireGuard и VLESS обновлено с 4.1.3 до **Fturn Core 4.2.2**. В нём исправлены восстановление после капчи и паузы авторизации. RAW остаётся на **FturnRaw 1.0.0**.
- После скачивания окно готовности к установке и сообщения об ошибках показываются на любом экране, включая настройки.
- На Android 8+ приложение открывает разрешение «Установка из этого источника» и продолжает установку после разрешения и возврата.
- Скачанный и проверенный APK сохраняется для повторной установки и восстанавливается после перезапуска приложения без повторной загрузки.
- Ошибки пакета, подписи и версии APK объясняются отдельно. Обычный релиз не может обновить отладочные пакеты Fturn RAW/.debug.
- В «О приложении» отображаются версии обоих ядер. Сборка использует закреплённые версии; опубликованный APK проверяется на соответствие выбранному ядру.

Пакет релиза: `com.litar.freeturn`, прежняя подпись Fturn. Android 7.0+, arm64-v8a. Загрузка обновлений через активный WG/VLESS/RAW сохранена.
