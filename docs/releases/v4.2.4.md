# Fturn 4.2.4

- Исправлен принудительный перезапуск всего ядра при ошибке TURN `486: Allocation Quota Reached`. Работающие сессии и авторизация сохраняются, а ядро само повторяет подключение затронутых сессий. Это устраняет лишнюю повторную авторизацию и запросы капчи из-за этого перезапуска.
- Восстановление после завершения процесса и смены сети сохранено.
- Ядро WG/VLESS: **Fturn Core 4.2.3**. RAW: **FturnRaw 1.0.0**. Подробная диагностика капчи, цвета сообщений и исправления установки APK из 4.2.3 включены.

Пакет: `com.litar.freeturn`, прежняя подпись Fturn. Android 7.0+, arm64-v8a.
