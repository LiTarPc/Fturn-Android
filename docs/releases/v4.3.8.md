# Fturn 4.3.8 — тестовый кандидат

Добавлен полный продвинутый браузерный этап проверки для RAW и обычного TURN:
фоновый WebView получает настоящий браузерный PoW, затем ядро продолжает
автоматическое решение и авторизацию. Получение PoW и токена не выдаётся за
готовое подключение. При необходимости сохраняется отдельная ручная проверка.

Переключатель «Продвинутое решение капчи» использует сохранённую настройку
фоновой проверки и применяется при следующем подключении. Ручной режим
профиля имеет приоритет. Настройка сохраняется в зашифрованных резервных копиях.

RAW обновлён до 1.0.1-beta.android.6, TURN — до 4.2.4-test.4. Сохранены
исправления передачи данных, ограничения повторов и паузы провайдера.
Несовместимый протокол теперь завершает попытку с видимой ошибкой без
автоматического перезапуска. Поздние события старого процесса отбрасываются.

Это кандидат для испытаний. Локальные ответы и проверка WebView не доказывают
принятие результата живым VK. Стабильный релиз в рамках этой работы не опубликован.

Исправлен момент запуска таймера DTLS в TURN: ожидание авторизации и подготовки
канала больше не расходует бюджет самого рукопожатия. Сохраняется первичная
причина сбоя; отмена и очистка ресурсов покрыты отдельными регрессионными тестами.
