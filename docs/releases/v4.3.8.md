# Fturn 4.3.8

Продвинутая автокапча для RAW и TURN, исправления раздачи SOCKS5 и запуска DTLS.

- Добавлен полный фоновый браузерный этап проверки VK: приложение получает браузерный PoW, затем ядро продолжает автоматическое решение и авторизацию. Готовность подключения определяется по доступным каналам. Ручная проверка сохранена для случаев, когда её требует VK.
- Продвинутая автокапча включена по умолчанию. Переключатель доступен в обычном пользовательском режиме: **Настройки → Приложение → Подключение → Продвинутая автокапча**. Выбор сохраняется после перезапуска и применяется при следующем подключении. Принудительный ручной режим профиля сохраняет приоритет.
- Исправлена общая SOCKS5-раздача: UDP-ассоциация завершается при закрытии или сбросе управляющего TCP-соединения, в том числе до первого UDP-пакета. Устранены утечки ресурсов при ошибке ответа и повреждённом первом пакете.
- Исправлен запуск таймера DTLS в TURN: ожидание авторизации и подготовки канала больше не расходует время самого рукопожатия. В журнале сохраняется первичная причина сбоя.
- Оба ядра используют согласованный протокол фоновой проверки. Поздние события старого процесса отбрасываются, несовместимый протокол завершает попытку с видимой ошибкой без повторных перезапусков.
- Закреплены исходники и сборки ядер: **RAW 1.0.1-beta.android.6**, **TURN 4.2.4-test.4**. Настройка автокапчи сохраняется в зашифрованных резервных копиях.

На физическом Android-телефоне проверены подключение обоих режимов, фоновая авторизация VK, HTTPS и UDP, сохранение пользовательского переключателя и **22 сетевые проверки SOCKS5 — по 11 в TURN и RAW**. Пройдены 211 JVM-тестов, Android lint и проверки Go, включая race detector и регрессии DTLS. Релизная сборка повторяет обязательные проверки перед публикацией.

APK: **Android 7.0+ / arm64-v8a**, пакет `com.litar.freeturn`. Используется прежний сертификат подписи для обновления установленного приложения с сохранением профилей. В релизе также опубликованы исходные снимки обоих ядер, лицензии, метаданные и SHA256SUMS.txt.

В журналах испытаний встречались временные ошибки DNS при авторизации RAW и разрывы транспорта TURN; их общее устранение этим релизом не заявляется. Выполнены функциональные проверки и тесты раздачи через Wi-Fi LAN. Длительный нагрузочный прогон и отдельная проверка точки доступа Android в этот цикл испытаний не входили.
