# Fturn 4.3.9

Кандидат обновления: стабильная публикация ожидает проверки нового APK на телефоне и роутере.

- IP-туннель роутера через USB без root на Android. Автоматическая привязка по общему коду получает текущие адреса сама; SOCKS5 для этого режима не требуется. MTU по умолчанию 1350.
- Исправлено зависание на «Продолжаю авторизацию»: готовое соединение убирает старую плашку, а зависшая авторизация без рабочих каналов запускает ограниченное восстановление. Явное ожидание ручного ввода капчи сохраняется.
- TURN обновлён до FTcore 4.2.6 с исправлением путей ресурсов ручной капчи и обновлениями безопасности Go/зависимостей.
- RAW использует проверенный коммит df69f213 из PR #1 к ядру 1.1.0. Номер Android-варианта 1.1.0-captcha.1 отличает его от опубликованного 1.1.0 без этой правки.
- Импорт ссылок turn-proxy-android читает VK-ссылку из поля vk, сохраняя поддержку links. Если звонок не указан, поле ввода доступно в обычном режиме и получает фокус.

Для IP-туннеля на OpenWrt нужны совместимые модули FOU/IPIP и помощник Fturn. В архив помощника включены инструкции; он рассчитан на описанную конфигурацию OpenWrt и не является универсальным установщиком. USB-модем включается в настройках Android. После восстановления резервной копии режим нужно включить заново.

Предыдущие проверки подтвердили автопривязку, передачу DNS/HTTPS и восстановление при изменении USB-сети на подготовленном Omni. Финальная приёмка именно этой сборки, длительная нагрузка и свежая ручная капча VK ещё не завершены.
