# Fturn 4.4.1

Обновление RAW до [FturnRaw 1.1.1](https://github.com/LiTarPc/fturn-raw/releases/tag/v1.1.1). В режиме TCP-flow обычный перенос TCP-соединения между TURN-каналами выполняется при пустой локальной очереди и по пакету с данными. Обычный ACK без данных не запускает перенос. Это уменьшает риск, что новые данные обгонят поставленные в очередь пакеты. Быстрый переход при ретрансмиссии сохранён.

В коротких тестах на телефоне кандидат полностью передавал тестовый объём через TURN по TCP. Скорость менялась между прогонами. Существующие RAW-профили и сервер 1.1.0 совместимы с этим обновлением.

Для обновления установите `fturn-4.4.1-arm64-v8a.apk` поверх Fturn. Название, идентификатор `com.litar.freeturn` и подпись сохранены. Поддерживаются Android 7.0 и новее на ARM64. Контрольные суммы опубликованы в `SHA256SUMS.txt`.
