# Fturn 4.3.3 - SOCKS timeout candidate

An unreachable RAW destination previously produced a misleading EOF in sing-box
after about 15 seconds: the client handshake deadline expired before the outbound
dial could send its SOCKS failure reply. The bridge now leaves a bounded reply
window and reports host unreachable for a timeout, preserving connection refused
for an immediate refusal.

RAW core: 1.0.1-beta.android.3. The sing-box -> RAW architecture, TCP DNS and
1024-handler limit are retained. This correction does not make a timed-out remote
server reachable and does not establish that the user's intermittent router-path
stalls are resolved. The version is distinct from the installed/published 4.3.2.

The regression first failed with EOF on the previous host implementation, then
passed after the fix. The complete RAW SOCKS and RAW transport host suites passed;
all 13 top-level SOCKS tests passed on Android ARM64, including 1024-client
admission, timeout/refused failure replies, TCP/UDP and cleanup. APK installation
and actual router-path validation are pending.
