# Fturn 4.2.5

- Добавлено уведомление о переходе на резервный DNS. Если обычный DNS не отвечает и ядро переходит на DoH, приложение сообщает об этом. Отдельное сообщение показывается, если DNS текущей сети не найден.
- В открытом приложении появляется всплывающий текст, в фоне — отдельное уведомление. Повторные сообщения ядра не создают повторных оповещений в рамках одного подключения.
- DNS текущей сети выбирается из физического Wi-Fi или мобильного подключения, а не из VPN-интерфейса. Выбор физического интерфейса согласован с VPN-службой; недоступная Wi-Fi-сеть не подменяет рабочую мобильную сеть.
- Явно выбранный DoH не считается аварийным переходом. Ручной DNS-список сохраняет приоритет над переключателем DNS оператора.

Раздел DNS отвечает за подключение к сервису. DNS сайтов обслуживается отдельно внутри VPN.

Ядро WG/VLESS: **Fturn Core 4.2.3**. RAW: **FturnRaw 1.0.0**. Исправление принудительных перезапусков при квоте из 4.2.4 сохранено.

Пакет: `com.litar.freeturn`, прежняя подпись Fturn. Android 7.0+, arm64-v8a.
