# Fturn 4.3.6

Исправлена очистка простаивающих UDP-ассоциаций RAW. После двух минут без
трафика в обоих направлениях ядро закрывает ассоциацию и освобождает место для
новых соединений. Активная отправка и загрузка сохраняют соединение.

Связанная правка sing-box завершает старое UDP-соединение после закрытия
управляющего TCP со стороны ядра. Добавлена диагностика занятых слотов,
TCP/UDP-обработчиков, отказов при заполнении лимита и причин завершения.

RAW обновлён до 1.0.1-beta.android.4. Лимит остаётся 1024, прежние исправления
переподключения сохранены. Достижение лимита при историческом сбое пока не
подтверждено; новые счётчики позволяют проверить эту гипотезу при повторении.

Подписанный APK установлен и проверен на Honor: 216 DNS/HTTPS-проверок прошли,
простаивающая ассоциация закрылась через 121,55 секунды, новое соединение после
очистки работает без перезапуска VPN. Профиль и журнал сохранены. Длительная
работа через роутер требует отдельной проверки.
