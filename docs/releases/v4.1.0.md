# Fturn v4.1.0

- VLESS из поля `sb` теперь поддерживает TLS и REALITY, включая Vision для TCP.
- Добавлены WebSocket и стандартный gRPC с параметрами Host, path, early data и serviceName.
- При подключении через FreeTurn сохраняются SNI, ALPN, fingerprint, UUID и ключи REALITY; заменяется только TCP-адрес подключения.
- sing-box 1.12.0 пересобран с uTLS и gRPC. TLS использует сертификаты Android и проверяет сертификат по умолчанию.
- Исправлена обработка query-параметров в пути WebSocket.
- Неизвестные параметры, дубликаты и несовместимые комбинации отклоняются до подключения.
- Добавлены проверки передачи данных через локальный TCP-ретранслятор на конфигурациях, созданных Kotlin-парсером.

Все VLESS-профили по-прежнему подключаются через FreeTurn. Прямой импорт `vless://` без JSON-обёртки, XHTTP, VLESS Encryption кроме `none`, gRPC multi и AmneziaWG не добавлены. Ссылка должна соответствовать VLESS-входу, к которому направляет поток удалённый FreeTurn.

Сохранены WireGuard, IPv4, встроенный RU IPdeny, `.srs` и исключения приложений. Android 7.0+ (API 24), arm64-v8a.
