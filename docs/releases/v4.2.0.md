# Fturn 4.2.0

- Добавлен RAW VPN с ядром FturnRaw **1.0.0**, импортом `fturnraw://` и поддержкой нескольких устройств на совместимом RAW-сервере 1.0.0.
- Обход IP-подсетей и поддерживаемых `.srs` списков работает в WG, VLESS и RAW. Меню «Обход сайтов» доступно в обычном клиентском режиме.
- Списки можно скачивать и импортировать при включённом VPN. Загрузка идёт через туннель, новые правила применяются при следующем подключении.
- Проверка обновлений и скачивание APK с GitHub проходят через активный WG/VLESS/RAW, включая перенаправления к файлу. При выключенном VPN используется обычное подключение. В окне загрузки отображается использование VPN.
- SOCKS5 Hotspot раздаёт VPN через настраиваемый порт без root. Поддержаны TCP и UDP, логин `fturn` и обязательный пароль. На получающем устройстве нужно указать SOCKS5-прокси.
- Обновлён интерфейс: тёплые светлые поверхности и бордовые акценты, полноценная тёмная тема. По умолчанию тема следует системной.
- В логах успешные соединения выделены зелёным, ошибки красным, предупреждения янтарным.
- Настройки темы и SOCKS5 включены в бэкапы.

Релизный пакет `com.litar.freeturn` обновляет обычную установку Fturn с сохранением профилей. Отдельное тестовое приложение `com.litar.freeturn.raw` остаётся отдельным.

Ограничения: Android 7.0+ (API 24), arm64-v8a, IPv4. RAW-мост передаёт TCP/UDP; ICMP/ping через него не проходит. Старый RAW-сервер без мультиустройственной поддержки не получит её от обновления клиента.
