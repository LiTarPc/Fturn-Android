# Автоматическое подключение OpenWrt через USB

Fturn передаёт трафик домашних устройств через выбранный VPN-профиль телефона. Первоначальная установка выполняется из приложения по SSH. После неё достаточно обычного USB-модема Android, ADB и отладка по USB не требуются.

## Требования

- OpenWrt с правами root, SSH и доступным репозиторием пакетов именно этой прошивки.
- USB-host, кабель передачи данных, поддержка Android RNDIS/NCM.
- netifd/ubus, основной LAN с частной IPv4-подсетью, стандартный dnsmasq.
- Firewall fw4/nftables или fw3/iptables.
- Доступные модули ядра FOU и IPIP. Установщик использует opkg или apk, не обходит проверку ABI.

Модель роутера не зашита в скриптах. Имена USB-устройства и LAN-моста определяются автоматически. Это не гарантия работы каждой заводской сборки: отсутствующий USB-host, недоступный модуль ядра, нестандартный DNS-сервис или неоднозначная топология требуют подготовки администратором. Установка на реальном парке моделей ещё не проверена.

## Первая настройка из Fturn

1. Подключите телефон к Wi-Fi роутера, чтобы был доступен его SSH. На роутере должен работать интернет для загрузки пакетов.
2. Откройте «Настройки → VPN → IP-туннель роутера → Настроить подключение к роутеру».
3. Укажите адрес, порт SSH (обычно 22), пользователя root и пароль.
4. Нажмите «Настроить роутер». Fturn проверит доступ root/OpenWrt, отправит скрипты из APK, установит зависимости и помощник, сохранит резервную копию DNS, включит автозапуск и создаст общую привязку.
5. Подключите телефон кабелем к USB-host роутера, включите USB-модем в Android и запустите VPN Fturn. При работающем VPN приложение переподключит его для применения нового IP-туннеля.

Пароль SSH используется только для текущей операции. Сохраняется отпечаток SSH-сервера: при его изменении повторная настройка блокируется. Код привязки создаётся автоматически и передаётся внутри SSH; вручную копировать его между телефоном и роутером при установке из приложения не нужно.

Настройка меняет DNS стандартного dnsmasq на 1.1.1.1/1.0.0.1, запросы к которым направляются через Fturn. Прежняя конфигурация сохраняется для сброса. Пользовательские WAN/HEV, UCI network и общие цепочки firewall не перезаписываются. Созданный DHCP-клиент USB является динамическим, без установки общего default route и DNS.

## Ежедневное использование

Помощник обнаруживает USB-сетевой адаптер по драйверу, повторно использует готовое DHCP-подключение или создаёт своё динамическое. Основной LAN выбирается по netifd; при нескольких мостах первоначальная SSH-сеть помогает определить нужную сеть. Выбранное логическое имя сохраняется. При действительно неоднозначной схеме помощник сообщает ошибку вместо переключения случайной сети.

Адреса и LAN передаются в аутентифицированной привязке. Fturn разрешает только частную каноническую IPv4-подсеть. По умолчанию MTU 1350; RAW/WireGuard MTU на удалённом сервере настраивается отдельно.

Привязка продлевается примерно каждые 2 секунды и действует 30 секунд. При единичном сбое управления сохраняется ещё действующий туннель; по окончании разрешения, отказе в авторизации или исчезновении USB его правила удаляются. Краткий отказ DNS не разрушает уже установленный туннель. Начальная проверка DNS по-прежнему выполняется до переключения LAN.

USB-модем и VPN могут требовать ручного включения после перезагрузки телефона; это зависит от Android. Работа через Wi-Fi вместо USB и несколько независимых роутеров одновременно не реализованы. Внешние IPv6-пакеты этим режимом не обслуживаются.

## Сброс

В Fturn есть две отдельные операции с подтверждением:

- «Сбросить IP-туннель в Fturn»: отключает приём, удаляет код и параметры привязки, переподключает работающий VPN. Роутер вернётся к прежней маршрутизации после окончания привязки, не позднее 30 секунд.
- «Сбросить настройки на роутере по SSH»: после ввода SSH-пароля останавливает и отключает автозапуск помощника, удаляет принадлежащие ему туннель/правила и восстанавливает резервную копию DNS. Если DHCP-конфигурация вручную менялась после установки, она не перезаписывается; резервная копия сохраняется и показывается ошибка для администратора.

Это не заводской сброс роутера. Установленные пакеты остаются, поскольку они могут использоваться другими службами.

Резервная команда по SSH:

```sh
/usr/sbin/fturn-router reset
```

Диагностика:

```sh
/usr/sbin/fturn-router doctor
/usr/sbin/fturn-router status
logread -e fturn-fou-auto
```

Данные помощника: `/etc/fturn-router/`; состояние: `/var/run/fturn-router/`; интерфейс: `ftfouauto`; таблица: `40081`; приоритеты правил: `1076–1078`. Занятые чужими настройками ресурсы не захватываются.

Для нестандартной схемы администратор может указать логическое имя LAN в `/etc/fturn-router/lan_network`, USB-устройство — в `/etc/fturn-router/usb_device`.
