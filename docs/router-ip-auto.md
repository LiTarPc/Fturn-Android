# Телефон → USB → OpenWrt-роутер

С Fturn 4.3.9 телефон может принимать трафик роутера через локальный IP-туннель и передавать его через выбранный VPN-профиль. Клиенты подключаются к Wi-Fi или LAN роутера как обычно. SOCKS5 на них настраивать не нужно.

На телефоне root не требуется. На роутере нужны OpenWrt и права администратора. Это экспериментальный режим для подготовленного роутера, а не универсальная функция любого заводского USB-модема.

## Если роутер уже подготовлен

1. На телефоне выберите рабочий профиль Fturn и убедитесь, что VPN подключается.
2. Откройте «Настройки → VPN → IP-туннель роутера».
3. Выберите «Автоматическая привязка». Укажите код этого роутера. Он должен совпадать с содержимым `/etc/fturn-fou-auto.key` на роутере.
4. Включите IP-туннель, сохраните параметры и переподключите VPN.
5. Подключите телефон к USB роутера и включите USB-модем в настройках Android.
6. Подключите компьютер или другое устройство к роутеру и проверьте открытие сайта.

IP-адреса телефона и роутера вводить не требуется: помощник получает их из текущей USB-сети. Если меняете телефон, установите Fturn, добавьте рабочий профиль и укажите тот же код привязки.

Если код остался в отдельном приложении «Fturn IP-туннель TEST», скопируйте его в обычный Fturn. Эти приложения не обмениваются настройками автоматически.

## Что означает каждая настройка

| Настройка | Что указывать |
|---|---|
| Код привязки | Одинаковый случайный код из 64 шестнадцатеричных символов на телефоне и роутере |
| Подсеть LAN роутера | Сеть устройств за роутером, например `192.168.1.0/24`, а не USB-сеть телефона |
| MTU | По умолчанию `1350`; допустимо 576–1400 |
| UDP-порты | По умолчанию `40080` на обеих сторонах |
| Автоматическая привязка | Определяет текущие адреса сама; TCP-порт управления — `40081` |

Дополнительные поля открываются кнопкой «Дополнительно». В обычной конфигурации менять нужно только код и, если отличается, подсеть LAN.

MTU локального туннеля не меняет MTU WireGuard или RAW на удалённом сервере. После изменения параметров приложения переподключите VPN.

## Подготовка нового OpenWrt-роутера

Эта часть предназначена для администратора. Готовый помощник рассчитан на следующие имена и компоненты:

- LAN: `br-lan`.
- USB-устройство: `usb0`.
- Логическая сеть USB с DHCP-клиентом: `usbwan`.
- Firewall: fw4/nftables.
- Модули FOU/IPIP, `ip-full`, `coreutils-timeout`, `jsonfilter` и команды `ubus`, `nc`, `flock`.

Если в вашей системе другие имена интерфейсов, помощник нужно адаптировать до запуска. Автоматическая настройка через Wi-Fi в этом выпуске не предусмотрена. Проверенная база — OpenWrt 24.10.8 на Keenetic Omni; работа произвольных моделей и заводских прошивок не подтверждена.

### 1. USB-сеть и пакеты

Сначала проверьте обычный USB-модем: в LuCI создайте или проверьте интерфейс `usbwan` с DHCP-клиентом на устройстве `usb0`. Для нового USB-uplink назначьте подходящую WAN-зону. Модули USB-сетевого адаптера зависят от телефона и сборки OpenWrt и устанавливаются на этом этапе.

Для OpenWrt 24.10 с `opkg` пакеты туннеля устанавливаются из репозитория именно вашей прошивки:

```sh
opkg update
opkg install ip-full coreutils-timeout kmod-fou kmod-ipip jsonfilter
```

Проверьте свободное место в `/overlay` до установки. Модули ядра должны соответствовать текущему kernel ABI; принудительный обход этой проверки не подходит.

Проверьте инструменты и состояние сети:

```sh
test -x /usr/libexec/ip-full
command -v timeout
command -v jsonfilter
command -v nc
command -v flock
ubus call network.interface.usbwan status
```

Все команды должны быть доступны, а `usbwan` — иметь состояние `up`, IPv4 и маршрут через телефон. Если отдельной команды нет в вашей сборке, установите её штатный пакет или соответствующую утилиту BusyBox.

### 2. Файлы помощника

Скачайте `fturn-router-openwrt-helper-4.3.9.tar.gz` из [релиза](https://github.com/LiTarPc/Fturn-Android/releases/tag/v4.3.9) и передайте его в `/tmp` роутера. Архив содержит помощник, сервис, определение USB-адресов и эту инструкцию.

На роутере:

```sh
mkdir -p /tmp/fturn-router-439
tar -xzf /tmp/fturn-router-openwrt-helper-4.3.9.tar.gz -C /tmp/fturn-router-439

if [ -x /etc/init.d/fturn-fou-auto ]; then
    /etc/init.d/fturn-fou-auto stop
fi
cp /tmp/fturn-router-439/scripts/router/fturn-fou-auto.sh /usr/sbin/fturn-fou-auto
cp /tmp/fturn-router-439/scripts/router/fturn-fou-auto.init /etc/init.d/fturn-fou-auto
chmod 755 /usr/sbin/fturn-fou-auto /etc/init.d/fturn-fou-auto

if [ ! -e /usr/sbin/fturn-hotspot-upstream ]; then
    cp /tmp/fturn-router-439/scripts/router/fturn-hotspot-upstream /usr/sbin/fturn-hotspot-upstream
    chmod 755 /usr/sbin/fturn-hotspot-upstream
fi
/usr/sbin/fturn-hotspot-upstream
```

Последняя команда выводит три значения: IP телефона, IP роутера в USB-сети и индекс USB-интерфейса. Несмотря на прежнее имя `fturn-hotspot-upstream`, этот файл только определяет USB-адреса: установка HEV или SOCKS5 ему не нужна.

Существующий файл с таким именем автоматически не перезаписывается: он может использоваться другой настроенной схемой раздачи. Проверьте его совместимость с нужными USB-интерфейсами.

### 3. Код привязки

На телефоне в настройках IP-туннеля создайте код и скопируйте его. Запишите тот же код на роутере. Чтобы не включать значение в командную строку, можно использовать интерактивный ввод:

```sh
umask 077
cat > /etc/fturn-fou-auto.key
```

Вставьте только код, нажмите Enter, затем Ctrl+D. После этого:

```sh
chmod 600 /etc/fturn-fou-auto.key
```

Файл должен содержать одну строку из 64 символов `0–9`, `a–f` или `A–F`. Создание нового кода только на телефоне не обновляет файл роутера.

Код и IP-пакеты локального FOU передаются без отдельного шифрования. Используйте выделенное доверенное USB-соединение. Удалённое VPN-соединение защищается выбранным протоколом Fturn.

### 4. DNS и запуск

Помощник проверяет DNS через `1.1.1.1` перед переключением клиентов. Он также направляет собственные запросы роутера к `1.1.1.1` и `1.0.0.1` через созданный туннель.

На новом роутере настройте DNS-forwarding dnsmasq на эти адреса и отключите получение внешних резолверов из `resolv.conf`, если хотите, чтобы DNS роутера шёл этим путём. В LuCI это параметры DNS-пересылки и «Игнорировать resolve-файл». Существующие локальные зоны, AdGuard Home или DoH требуют согласования с вашей схемой; помощник их автоматически не меняет.

Включите IP-туннель и VPN на телефоне, затем запустите сервис:

```sh
/etc/init.d/fturn-fou-auto enable
/etc/init.d/fturn-fou-auto start
logread -e fturn-fou-auto | tail -n 20
```

Успешное создание маршрута отмечается сообщением `FOU ready`. После него проверьте DNS и HTTPS с устройства за роутером. Одного наличия файла состояния недостаточно для проверки интернета.

## Повседневная работа и восстановление

Помощник обновляет привязку примерно каждые три секунды. Она истекает через 12 секунд без продления. При потере USB, выключении VPN, неверном коде или неуспешной проверке помощник удаляет свои маршруты. После восстановления условий он пытается подключиться снова.

Он возвращает прежнюю маршрутизацию роутера. Если до него был настроен HEV, для работы этого резерва нужны доступный SOCKS5 телефона и совпадающие реквизиты. Если прежним путём был обычный WAN, после снятия маршрутов может использоваться обычный WAN. Автоматическая привязка сама по себе не является блокировкой выхода в обход VPN.

Для постоянной раздачи проверьте, что Android разрешает фоновую работу Fturn. После восстановления резервной копии приложения IP-туннель включается пользователем заново.

## Диагностика и остановка

```sh
/etc/init.d/fturn-fou-auto enabled
ubus call service list '{"name":"fturn-fou-auto"}'
logread -e fturn-fou-auto | tail -n 30
/usr/sbin/fturn-hotspot-upstream
ip -4 rule
```

| Ситуация | Что проверить |
|---|---|
| Нет адресов USB | USB-модем телефона, `usb0`, DHCP и имя сети `usbwan` |
| Адреса есть, но нет `FOU ready` | VPN телефона, совпадение кода, модули FOU/IPIP, наличие инструментов |
| Ошибка подсети | Поле LAN в Fturn должно точно совпадать с сетью `br-lan` |
| Маршрут появился, сайты не открываются | DNS, рабочий профиль VPN, доступность сервера, MTU и журнал |
| Резерв HEV не работает | Включена ли SOCKS5-раздача и совпадают ли порт и пароль |

Остановить и отключить автозапуск:

```sh
/etc/init.d/fturn-fou-auto stop
/etc/init.d/fturn-fou-auto disable
```

Сервис удаляет только принадлежащие ему правила и интерфейс. Имена ресурсов: `ftfouauto`, таблица `40081`, приоритеты `1076–1078`. Конфигурацию прежнего HEV он не редактирует.
