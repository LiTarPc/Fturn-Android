# Пустая страница ручной CAPTCHA: пути ресурсов CDN

Подтверждено по журналу браузера и общедоступному загрузчику VK `entry.243b7a49.js`.
Загрузчик вычисляет webpack publicPath из document.currentScript.src: удаляет
query, имя файла и добавляет ../. Адрес старого proxy endpoint хранит upstream
в query, поэтому получался корень localhost вместо каталога проекта на st.vk.ru.

Наблюдавшиеся `iui_subapp.a79f2d53.js` и `394.e400a060.js` запрашивались как
`http://localhost:8765/chunks/js/...` и попадали на основной upstream CAPTCHA,
а не на CDN. Ответ 404/HTML вызывал вторичную ошибку MIME. Та же потеря каталога
затрагивает CSS и относительные URL шрифтов. Надпись Ftcore — captcha означает
только выполнение showPending() нашего инжектора.

## Исправление

Оба ядра формируют локальные адреса вида
`/local-captcha-resource/<base64url-origin>/<полный исходный путь>?query`.
Имя, каталог и относительные переходы сохраняются в browser-visible pathname.
Новый и старый /generic_proxy маршруты используют один обработчик и тот же
список допустимых доменов. Методы/тело fetch(Request), HTTP-статусы и MIME
ресурсов сохраняются. Ограничения browser-PoW-capture продолжают действовать.
Отдельный 403 рекламного ad.mail.ru не маскируется разрешением всех доменов.

## Проверки

- Go-регрессии обоих VK-провайдеров, ручного HTTP-сервера и IPC прошли.
- Namespace/HTTP тесты воспроизводят точные имена двух упавших JS-чанков,
  пути CSS/шрифтов, query-параметры, MIME, 404 и запрет посторонних доменов.
- `node scripts/tests/captcha_resource_paths.mjs` проверяет JS-инжекторы обоих
  ядер, publicPath, относительные чанки, HTTPS и сохранение POST Request.
- Публичные CDN URL двух JS-чанков и CSS вернули HTTP 200 с JavaScript/CSS MIME.
  Пользовательский session_token не запрашивался и не использовался.
- Windows-ядро собирается отдельно от установленного PC-приложения.
- Полный цикл новой живой CAPTCHA VK и отображение её виджета пока не подтверждены.

Поставляются тестовый Windows-архив и Android APK с предыдущими исправлениями
авторизации/автопривязки. Стабильный релиз не публикуется. Ключи и профили
пользователей в дистрибутив не включаются.
