# Обновление Fturn и перенос данных

## Обновление обычного приложения

Релизный APK обновляет пакет `com.litar.freeturn` и подписан ключом проекта. Установка поверх прежней версии сохраняет данные Android-приложения, включая профили и настройки. Перед важным обновлением можно дополнительно сохранить резервную копию через настройки Fturn.

Откройте проверку обновлений в «О приложении» либо скачайте APK со [страницы релизов](https://github.com/LiTarPc/Fturn-Android/releases). При активном VPN встроенный загрузчик передаёт запросы и файл через выбранное подключение. При выключенном VPN используется обычная сеть.

После скачивания Fturn проверяет пакет приложения, подпись и код версии. На Android 8+ при необходимости открывается разрешение на установку из этого источника; после возврата приложение повторно проверяет разрешение и запускает установщик Android.

Готовый проверенный APK сохраняется для повторного запуска установки. Ошибки скачивания, несовпадения пакета, подписи и версии показываются отдельно.

## Обычный Fturn и тестовые приложения

| Сборка | Пакет | Что обновляет |
|---|---|---|
| Обычный релиз | `com.litar.freeturn` | Прежние обычные релизы Fturn |
| Debug текущего проекта | `com.litar.freeturn.routerip` | «Fturn IP-туннель TEST» с совместимой debug-подписью |
| RAW debug с `-PrawBuild=true` | `com.litar.freeturn.raw.routerip` | Отдельную RAW-тестовую сборку |

Это разные приложения с разными хранилищами и разрешениями Android. Релизный APK не заменяет тестовый пакет. Профиль и код привязки роутера из «Fturn IP-туннель TEST» не переносятся в обычный Fturn автоматически.

Если переходите из тестового приложения в обычное, перенесите нужные профили через предусмотренную резервную копию или импорт и задайте код роутера в новом приложении. Убедитесь, что запущен нужный экземпляр VPN.

## Резервная копия и роутерный режим

После восстановления резервной копии IP-туннель остаётся выключенным. Проверьте параметры роутера и код привязки, затем включите его вручную. Изменение кода только на телефоне не меняет код на роутере.

В «О приложении» отображаются отдельные версии FTcore и RAW. Они не обязаны совпадать с версией Android-приложения. Оба ядра входят в APK; отдельно заменять файлы на телефоне для обычного обновления не нужно.

Технические отчёты прежних установочных проверок сохранены в [архиве](archive/updater-history.md).
