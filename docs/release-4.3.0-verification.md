# Проверка Fturn 4.3.0

## Зафиксированные зависимости

- TURN: 4.2.4-test.1, snapshot dfe302775334b7e5eaf10e9235e6c2a6be8f6b5d5c2ae42311727fa28ed1fce5. Проверенные исходники локальной клиентской сборки, без изменения серверного протокола 4.2.3.
- RAW: опубликованный тег 1.0.1-beta, base 4b1a2bd3384e9fde84152419c5c6241760a2b643, snapshot ed20458f0adad9bf54d2615a5b0350dcea48e368222e90ca2cecb60a7c9e7db5. Добавлена только точка входа Android через существующий аутентифицированный SOCKS-мост.
- Go: 1.26.10, Android/arm64, CGO=0, PIE. Оба ядра собираются из проверяемых исходников в Gradle; старое автоматическое скачивание ядра 4.2.3 отключено.

## Завершённые проверки

- Windows: прошли Go-регрессии RAW SOCKS, rawvpn и turndial, а также TURN netconn, turndial, tcprelay, udprelay, session и config.
- Honor TFY-LX1: оба CLI запускаются и возвращают нужную версию.
- Honor TFY-LX1: прошли 7 тестов RAW SOCKS и пакет rawvpn, включая локальные TURN TCP/UDP, rtpopus2/rtpopus3, lease, повторные подключения и передачу Android TUN-дескриптора. Opt-in внешний deployment test штатно пропущен; это не подменяет живое подключение к пользовательскому серверу.
- Honor TFY-LX1: прошли 17 тестов TURN turndial — отмена Allocate, общая квота, подтверждение закрытия и обработчики обновления аллокаций.
- Подтверждён дефект вертикальной прокрутки в 4.2.6. Встроенные экраны имели nested-scroll обработчик скрытой схлопывающейся верхней панели. В 4.3.0 он отключён только во встроенном режиме; самостоятельные экраны сохраняют поведение.
- Локальная Android-сборка остановилась из-за отсутствия места на C:. Удалены только пересоздаваемые app/build/intermediates внутри проекта, освобождено около 674 МиБ. Основные Android-тесты, Lint и подписанная сборка выполняются на GitHub.

Итоговые результаты приведены ниже; публикация выполняется после проверки телефона.

## Живое подключение RAW (проверочная 4.3.0)

Подписанный APK из run 40229776940 установлен поверх 4.2.6. Сертификат, versionCode 40300, applicationId и хеши обоих нативных ядер проверены. RAW-профиль подключился, UI показал активный туннель. HTTPS вернул 200, внешний адрес совпал с RAW-сервером (до подключения совпадения не было), TCP DNS и UDP DNS вернули корректные ответы. В процессе работало ровно одно RAW-ядро и ни одного legacy TURN-ядра.

## Живое подключение TURN/WireGuard (проверочная 4.3.0)

Профиль adminNetherLand подключился с новым TURN-клиентом. HTTPS вернул 200 с внешним адресом сервера, TCP DNS и UDP DNS — корректные ответы. После штатной остановки не осталось процессов libfreeturn.so/libfturnraw.so. Отдельно подключение отменено через 300 мс после начала; UI вернулся в исходное состояние, процессов ядра не осталось. Следующий запуск снова достиг активного туннеля. Между тестами пользователь вручную переключал профиль; это не было автоматической сменой из приложения.

## Финальный APK с исправленной прокруткой

Run 40230394567, исходники 65745901de92e368817982de85f3a7e18e2dab20: все этапы Actions успешны, включая Go-регрессии, Android unit tests, Lint, release-сборку, проверку native provenance и release-сертификата.

SHA-256 APK: 3c9ab1bef6cfb677d0a6d42951c7dea70aa0d758f6fb8e7a2b05b32a9f8c7bef.

APK установлен поверх проверочной 4.3.0. Native SHA-256 совпадают с прошедшими живые тесты ядрами: TURN 874540e76158eedbf0c4ec2e43fd2dda5e530025c0c2bb44b2de663e3082324e, RAW c4a37d529cbe3e0c6abed718ae2aef487251becd0295da2204e742a1c9c798a6.

На финальном APK жестами проверена вертикальная прокрутка обеих вкладок: в TURN показан раздел DNS, в Прокси и VPN показаны поле «Имя туннеля» и нижний переход VPN. Оба профиля сохранены, последним активным остался выбранный пользователем adminNetherLand. Имя Fturn, пакет com.litar.freeturn, версия 4.3.0 / 40300, прежний release-сертификат.

Проверка не заменяет длительную эксплуатацию, нагрузочный тест скорости, принудительный handover Wi-Fi/мобильной сети и живой VLESS: отдельного VLESS-профиля в этой проверке не использовалось. Обозначения test/beta встроенных ядер сохранены честно.

## Публикация

Fturn 4.3.0 опубликован как обычный Latest-релиз: https://github.com/LiTarPc/Fturn-Android/releases/tag/v4.3.0.

Публикация проверенного артефакта выполнена через Actions run 40272586497. Тег указывает на 94df48eba2bd9b68e44060b514f10c5e66f62919; исходники приложения, ядер и сборки совпадают с проверенным build commit 65745901de92e368817982de85f3a7e18e2dab20, различаются только документы. Все 8 опубликованных файлов совпали по размеру и SHA-256 с локальными; APK совпадает с установленным финальным APK. Исходники обоих ядер, provenance JSON, лицензии и SHA256SUMS включены в релиз.

Прямая загрузка с ПК первоначально остановилась по таймауту. Первый проход workflow публикации потребовал исправить каталог распаковки артефакта; повторный проход успешно проверил исходники, загрузил все файлы, проверил удалённые хеши и опубликовал релиз без пересборки APK.
