# WireGuard и VLESS через Fturn

WireGuard и VLESS в Fturn 4.3.9 используют общий VPN-движок sing-box 1.14.4 и FTcore 4.2.6. Параметры удалённого сервера должны соответствовать выбранному протоколу.

## WireGuard

Импортируйте профиль Fturn с WG-конфигурацией или укажите её в настройках режима подключения. В ней должны быть ключи, внутренний IPv4, разрешённые подсети и параметры совместимого сервера.

Приложение направляет первого WG-пира через локальный слушатель FTcore. Для этого на удалённой стороне должно быть настроено соответствующее перенаправление на WireGuard. Один обычный WG-конфиг произвольного сервера без этой связки не гарантирует подключение через Fturn.

MTU WireGuard в этой схеме фиксирован на `1280`. Он не связан с локальным MTU `1350` IP-туннеля роутера. Режим передачи WG остаётся UDP, даже когда сам транспорт до TURN выбран TCP.

Поддерживаются IPv4-конфигурации и IPv4 AllowedIPs. Для профилей с неполными AllowedIPs DNS-сервер должен быть доступен через выбранного пира.

## VLESS

Профиль Fturn может содержать одну VLESS-ссылку в поле `sb`. Её также можно задать в параметрах соответствующего режима. В одном профиле нельзя одновременно передавать `wg` и `sb`.

| Параметр VLESS | Поддержка |
|---|---|
| Транспорт | TCP, WebSocket, обычный gRPC |
| Защита | Без TLS, TLS, REALITY |
| Flow | Пустой либо `xtls-rprx-vision` для TCP с TLS/REALITY |
| Encryption | `none` |
| Дополнительные параметры | SNI, ALPN, поддерживаемые fingerprints, REALITY key/short ID, WS Host/path/early data, gRPC service name |

XHTTP, HTTP-заголовки поверх TCP и gRPC multi mode не реализованы. Неподдерживаемые и несовместимые параметры отклоняются при разборе. `spx` принимается как метаданные ссылки, но sing-box не использует SpiderX.

Соединение идёт так:

```text
Приложение Android → VPN Fturn → VLESS → FTcore → удалённый сервер Fturn → VLESS-вход
```

Адрес подключения VLESS во время работы заменяется локальным слушателем FTcore. SNI, WS Host и параметры проверки удалённой стороны сохраняют смысл исходной ссылки. Сервер Fturn должен пересылать поток на совместимый VLESS-вход с правильным UUID.

Это не режим прямого VLESS-подключения к произвольному серверу без FTcore. Приложение также не создаёт VLESS-пользователя на сервере автоматически.

## Маршрутизация и DNS

Выбор приложений и обход IP-подсетей находятся в «Настройки → VPN». Для редактирования активного профиля сначала остановите VPN. Поддерживаются CIDR-списки `.zone`/`.txt` и поддерживаемые двоичные `.srs` версии 1–3. Файлы копируются в профиль и сохраняются в резервной копии; они не включаются в share-ссылку.

Для новых профилей предусмотрен встроенный список RU IPv4. Это список подсетей, а не полный каталог русскоязычных сайтов: размещённый за рубежом сайт может не попасть в него. Сохранённое пользователем выключенное состояние не должно заменяться новым значением по умолчанию.

IPv6-трафик внутри VPN отклоняется; обычные DNS-запросы обрабатываются согласно [политике DNS](dns.md). Выключение обхода и изменение выбора приложений применяются после переподключения.

## Если импорт прошёл, но интернета нет

Проверьте выбранный режим, ключи или UUID, адрес сервера, обфускацию и ссылку на звонок. Затем проверьте на сервере соответствующий WG-порт или VLESS-вход и перенаправление FTcore. Сам по себе успешный импорт ещё не проверяет серверную часть.

Параметры сборки и локальные протокольные проверки находятся в [руководстве разработчика](build.md). Старые прогоны вынесены в [архив](archive/vless-history.md).
