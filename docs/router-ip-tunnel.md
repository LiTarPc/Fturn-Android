# Устройство USB IP-туннеля

Пользовательская настройка: [автоматическое подключение OpenWrt](router-ip-auto.md).

```text
LAN → Linux IPIP/FOU на роутере → UDP по USB-сети → fturn-fou на телефоне
    → пользовательский стек gVisor → DNS/маршруты/выбранный профиль Fturn
```

Android VPN TUN не используется для инъекции чужих пакетов. Внешний IPv4-трафик принимает отдельный стек gVisor, а соединения обрабатывают общие правила Fturn. IPv6 через этот вход не реализован.

## Управление

По умолчанию данные идут по UDP 40080, управление — TCP 40081. Помощник роутера отправляет POST /v1/lease с Bearer-кодом из 32 случайных байт в hex. Только аутентифицированный запрос от частного IPv4-адреса может получить привязку. Другая пара адресов не заменяет действующего владельца до окончания его разрешения.

Если в Fturn включено auto_source_prefixes, заголовок X-Fturn-LAN позволяет определять LAN автоматически. Принимается только каноническая частная IPv4-подсеть /8–/32, полностью находящаяся в частном диапазоне. Старые настройки сохраняют фиксированные source_prefixes; старый помощник без заголовка использует их как fallback.

Ответ содержит текущие адреса, порты, MTU, разрешённые source_prefixes и lease_seconds. Привязка действует 30 секунд, продление выполняется примерно каждые 2 секунды. При кратком сбое HTTP сохраняется ещё действующая привязка, отказ авторизации выключает её сразу. Обычный успешный renewal не печатает сообщение о новой привязке.

FOU передаёт IPv4 без дополнительного шифрования. Локальное соединение предназначено для доверенной выделенной USB-сети; удалённое соединение защищается выбранным профилем Fturn. Код не возвращается в ответе и не записывается в журнал.

## Данные и жизненный цикл

Linux FOU ipproto 4 переносит один IPv4-пакет внутри UDP. Получатель проверяет peer, разрешённый источник, длину/версию IP, TTL и checksum; внутренние фрагменты обрабатывает стек. MTU по умолчанию 1350, допустимо 576–1400. Очереди ограничены, UDP NAT ограничен 4096 потоками.

Закрытие входа синхронизировано с записью принятых пакетов в gVisor: поздний UDP-пакет не обращается к уже закрытому dispatcher. Закрытие устройства освобождает заблокированный reader перед ожиданием завершения рабочих горутин.

## Помощник OpenWrt

Установщик отправляется из APK по SSH; ADB не используется. SSH-сокеты по возможности привязываются к непосредственно подключённой сети роутера. Отпечаток сервера сохраняется, пароль не сохраняется.

Помощник определяет сетевые устройства через netifd/ubus и USB-драйвер, поддерживает opkg/apk и fw3/fw4. Используются только собственные интерфейс ftfouauto, таблица 40081 и приоритеты 1076–1078; конфликтующие чужие ресурсы не захватываются. При необходимости DHCP для USB создаётся как динамическая сеть, без изменения пользовательской UCI network.

Начальная DNS-проверка выполняется до переключения LAN. Единичный сбой DNS не разбирает установленный туннель. Ошибка установки вызывает откат конфигурации DNS и прежних файлов помощника. Сброс на роутере отключает службу и удаляет только свои сетевые ресурсы; DNS восстанавливается из резервной копии при отсутствии последующих ручных изменений.

Проверки: scripts/tests/test_router_openwrt.py и Go-тесты scripts/patches/fou, включая авторизацию, изучение LAN, двусторонние TCP/UDP-соединения и закрытие приёмника. Эмуляция не заменяет проверку конкретной прошивки и реального USB-соединения.
