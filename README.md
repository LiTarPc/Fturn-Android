# Fturn

Android-приложение для подключения через TURN-серверы мессенджера на базе [fturn-core](https://github.com/LiTarPc/fturn-core).

**Возможности:** WireGuard, VLESS и RAW (ядро FturnRaw 1.0.0), импорт подключения по ссылке или QR-коду, раздельное туннелирование, обход IP-подсетей, SOCKS5 Hotspot без root и загрузка обновлений через активный VPN.

## Начало работы

1. Установите APK из [релизов](https://github.com/LiTarPc/Fturn-Android/releases).
2. Импортируйте профиль подключения по ссылке или QR-коду.
3. Укажите ссылку на звонок в мессенджере, если её нет в профиле.
4. Нажмите кнопку подключения и разрешите создание VPN-соединения.

**Требования:** Android 7.0 или новее, устройство ARM64 и настроенный сервер с ядром fturn-core либо готовый профиль доступа к нему.

VLESS поддерживает TCP, TLS/REALITY, WebSocket и gRPC. Доступные возможности зависят от установленной версии приложения.
