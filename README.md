# Fturn

Fturn — Android-клиент для подключения к настроенному VPN-серверу через TURN. Приложение поддерживает WireGuard, VLESS и RAW. Для подключения нужен готовый профиль доступа или собственный совместимый сервер.

**[Скачать Fturn 4.4.0](https://github.com/LiTarPc/Fturn-Android/releases/tag/v4.4.0)** · [Инструкции](docs/README.md) · [Что изменилось](docs/releases/v4.4.0.md)

## Начало работы

1. Установите релизный APK. Для обновления обычного Fturn установите его поверх прежней версии.
2. Добавьте сервер: вставьте ссылку подключения, откройте её в приложении или отсканируйте QR-код.
3. Если ссылка на звонок VK не передана в профиле, заполните появившееся поле.
4. Подключитесь и разрешите Fturn создать VPN-соединение.

Подробности: [первое подключение и импорт](docs/quick-start.md).

## Возможности

- WireGuard и VLESS через ядро FTcore; RAW через отдельное ядро FturnRaw.
- Импорт `freeturn://`, совместимых Base64-профилей и `fturnraw://`.
- Продвинутая автокапча включена по умолчанию; ручное подтверждение остаётся доступным, когда его требует VK.
- Выбор приложений для VPN и обход заданных IP-подсетей.
- SOCKS5-раздача с авторизацией для устройств, на которых настроен прокси.
- Экспериментальный IP-туннель для подготовленного OpenWrt-роутера через USB, без root на телефоне и без настройки прокси у клиентов роутера.
- Резервные копии профилей и загрузка обновлений через активный VPN.

Обычная точка доступа Android сама по себе не раздаёт соединение Fturn. Различия между SOCKS5 и роутерным режимом описаны в [руководстве по раздаче](docs/sharing.md).

## Требования и компоненты

Android 7.0 или новее, устройство ARM64 (`arm64-v8a`). Нужны действующий профиль, доступная ссылка на звонок для TURN-авторизации и совместимая серверная сторона.

| Компонент в 4.4.0 | Версия |
|---|---|
| FTcore для WireGuard/VLESS | 4.2.7 |
| FturnRaw для RAW | 1.1.0-captcha.2 — сборка с исправлением ресурсов капчи |
| Движок VPN и маршрутизации sing-box | 1.14.4 с исправлениями Fturn |

Настройки и доступность удалённого сервера определяют, какие режимы будут работать. VLESS используется внутри подключения Fturn; прямое подключение к произвольному VLESS-серверу не реализовано.
